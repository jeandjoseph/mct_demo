# Module 1
### **Lab 1: Build and run a container image with ACR Tasks**
#### Push a Local Container Image to Azure Container Registry (ACR)
- Root Directory: `./az_acr_container`
- For demonstration purposes, make sure the Docker application is up and running, although it is not strictly required for the Azure-based deployment workflow.
- Build and run the container locally:
  - `docker compose up -d --build`
- Verify the application is accessible at:
  - `http://localhost:8080`
- Stop and remove the local container resources when finished:
- `docker compose down`  
- Explain to learners that local containers work well for development, but enterprise workloads require:
  - Scalability
  - Managed container registries
  - Centralized image management
  - Governance and security controls
- Push the local container image to Azure Container Registry (ACR).
- Demonstrate how ACR can be integrated with Azure Container Apps, AKS, and CI/CD pipelines.
  - **Live Demo Directory:** `azure_ai_200/webcontainer/1_az_acr_cloud_build_pipeline.sh`
